# Jameson Web Studio brand assets

SVG files are the master artwork. PNG, favicon, social, email and document
assets are generated from those vector masters by
`scripts/generate-brand-assets.mjs`.

Start with:

- `svg/logo-horizontal-full-colour.svg` for general brand use
- `svg/logo-compact-full-colour.svg` for compact headers and navigation
- `svg/icon-square-full-colour.svg` when only the symbol fits
- `brand-guide/brand-guide.md` for usage rules
- `brand-guide/asset-index.md` for a file-by-file recommendation
- `brand-guide/brand-audit.md` for the pre-design website audit

The brand direction was approved on 20 July 2026. The current draft branch
connects the compact logo, responsive icon fallback, favicon set, manifest and
Open Graph image to the website. Merge, deployment and external account rollout
remain separate approval steps.
